Purpose

This folder contains a hands-on implementation pack to run the "First Gear" system from `matt.md` yourself.

Quick one-liner: I'm creating templates and a tracking sheet so you can implement First Gear yourself without Matt.

Checklist (start here)

1. Define your ICP using `templates/ICP.md`.
2. Draft your core offer in `templates/OFFER.md`.
3. Rewrite your LinkedIn profile with `templates/LINKEDIN_PROFILE.md` and publish it.
4. Set up the outbound research & cadence from `templates/OUTBOUND.md`.
5. Copy and adapt message templates from `templates/OUTBOUND_MESSAGES.md`.
6. Populate `templates/TRACKING_SHEET.csv` and use it to record prospects every day.
7. Schedule and follow the 30-day content plan in `templates/CONTENT_CALENDAR.md`.
8. Run weekly reviews and iterate on ICP/offer/content/outbound.

How to use these files

- Edit each template in place. Replace example text with your specifics.
- Use the CSV (`templates/TRACKING_SHEET.csv`) in Excel / Google Sheets / Notion for prospect tracking.
- For outbound, start with 10–15 researched prospects/day (or fewer while iterating).
- Keep a weekly review meeting (30–60 minutes) to tune the inputs.
