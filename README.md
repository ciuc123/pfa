# pfa — business + YouTube operating system

This repository contains two complementary subsystems:

- `strategy/` — productisation, offers, outbound templates and tracking (operational core).
- `youtube/` — content, experiments and channel strategy (distribution & validation).

New quick-start docs

- `business/setup.md` — single-page setup to run a productized service and wire YouTube into the funnel.
- `business/workflow.md` — prescriptive daily / weekly / monthly workflow to execute the product-first plan.

Usage

1) Read `business/setup.md` to finish the offer, ICP and tracking setup.
2) Follow `business/workflow.md` for daily and weekly actions.
3) Use `strategy/` templates for outreach and delivery and `youtube/` templates for video creation.

Key existing files

- `strategy/README.md` — operational checklist and templates for the "First Gear" system.
- `youtube/README.md` — YouTube operating system and guidelines.

If anything here is unclear, edit the appropriate file under `business/`, `strategy/` or `youtube/` rather than creating new scattered files.
