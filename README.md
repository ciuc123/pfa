# pfa — business + YouTube operating system

This repository contains three complementary subsystems:

- `strategy/` — productized service offers, ICP tools, outbound templates and tracking (operational core).
- `business/` — setup, workflow, and decision helpers that connect the productized service with YouTube distribution.
- `youtube/` — content, experiments and channel strategy (distribution & validation).

New quick-start docs

- `business/setup.md` — single-page setup to run a productized service and wire YouTube into the funnel.
- `business/workflow.md` — prescriptive daily / weekly / monthly workflow to execute the product-first plan.
- `business/ICP_PICKER.md` — step-by-step helper for choosing your first Ideal Customer Profile (start here if you don't know who to sell to).
- `strategy/BUYING_SIGNALS.md` — reference list of observable buying signals for technical productized services.
- `strategy/offers/` — candidate productized offers with full delivery methodology, for you to evaluate and pick from.

Usage

1. If you don't know your ICP yet, start with `business/ICP_PICKER.md`.
2. Read `strategy/BUYING_SIGNALS.md` to learn what signals indicate a warm prospect.
3. Browse `strategy/offers/` to see candidate offers and assess which ones you can deliver.
4. Pick your ICP, then pick an offer that matches.
5. Follow `business/setup.md` and `business/workflow.md` for daily and weekly execution.
6. Use `strategy/` templates for outreach and delivery and `youtube/` templates for video creation.

Key existing files

- `strategy/BUYING_SIGNALS.md` — observable triggers that a team needs technical help.
- `strategy/offers/README.md` — overview of candidate offers and how to use them.
- `strategy/README.md` — operational checklist and templates (from the First Gear system).
- `youtube/README.md` — YouTube operating system and guidelines.

If anything here is unclear, edit the appropriate file under `business/`, `strategy/` or `youtube/` rather than creating new scattered files.
