## Delivery Process Quality Checklist

Before you lock this in, confirm:

```
[ ] I've done this (or similar) 2+ times before
[ ] I can deliver it in [X] days or less
[ ] I could train someone else to do 80% of it
[ ] I've documented my process
[ ] The customer will see clear value (not subtle)
[ ] I'd be proud to share this with anyone
[ ] I can deliver 3+ times in 60 days
[ ] I'd want to do this 100 times (yes = good, no = wrong problem)
```
