# Creating a New Product: End-to-End Guide

Welcome to the product creation journey. This guide walks you through all 5 phases of building a new productized service or product, from idea to first customer.

**Time to first customer:** 30–60 days (if you follow the fast path)
**Effort level:** Medium — you'll be testing, validating, and shipping continuously

---

## The 5 Phases

| Phase | Focus | Time | Output |
|-------|-------|------|--------|
| **1. Ideation** | Find a problem worth solving | 3–7 days | Problem statement + early validation |
| **2. Validation** | Confirm 30+ prospects want this | 7–14 days | Validated ICP + proof of demand |
| **3. Design** | Define scope, delivery, pricing | 3–7 days | Service spec + pricing model |
| **4. Delivery** | Build the MVP delivery process | 5–10 days | Repeatable system ready for clients |
| **5. Launch** | Get your first 3 paid customers | 7–21 days | Proof clients + testimonials + case study |

## The Core Rules

Read these before starting:

1. **You are testing for 30 days, not choosing forever.** If something doesn't work, change it.
2. **Bad data beats no data.** A "good enough" product beats a perfect one that never launches.
3. **Ship first, perfect later.** You learn by doing, not by planning.
4. **Done is better than perfect.** Your first 3 customers will teach you what you actually need to build.
5. **Focus on one thing.** Pick ONE problem, ONE ICP (customer type), ONE offer. Perfect it later.

---

## How to Use This Guide

1. **Read the phase you're in** (pick from the table above)
2. **Do the exercises** in that phase (mandatory, not optional)
3. **Answer all the reflection questions** — write them down
4. **Move to the next phase only when you have proof** (not when you're "ready")
5. **Use the templates** provided for each step

**Do NOT skip ahead.** Each phase builds on the previous one. If you skip validation, you'll waste time building for the wrong customer.

---

## The Fast Path (Recommended)

If you're overwhelmed by choices, follow this sequence:

1. **Day 1–3:** Ideation phase (identify your problem)
2. **Day 4–10:** Validation phase (talk to 10–15 prospects)
3. **Day 11–14:** Design phase (lock in your spec and pricing)
4. **Day 15–24:** Delivery phase (build your process)
5. **Day 25–30:** Launch phase (get first customers)

This assumes you already have domain expertise. If you don't, add 2–3 weeks to each phase.

---

## What Success Looks Like

**After 30 days, you should have:**

- ✅ A clear problem statement validated by 10+ prospects
- ✅ A defined service/product spec with delivery timeline
- ✅ A pricing model you've tested with at least 1–2 customers
- ✅ 1–3 paid customers (at MVP pricing, €500–1,500 each)
- ✅ A repeatable delivery process (not fully polished, but documented)
- ✅ First case study or testimonial from a customer

**After 60 days, you should have:**

- ✅ 5–8 paid customers
- ✅ Repeatable delivery (60% faster than your first delivery)
- ✅ 2–3 case studies or testimonials
- ✅ Clear picture of what to improve next
- ✅ Data on what messaging works best

## Quick FAQ

**Q: I don't know what product to build.**
A: Start with Phase 1 (Ideation). Do the exercises. They'll guide you to a problem you can solve.

**Q: How much does this cost to build?**
A: Nothing if you're using your existing skills. Budget €0–500 for tools if needed (landing page, scheduling, etc.). But start with zero budget and add tools only when you need them.

**Q: What if nobody wants my product?**
A: That's why you validate BEFORE building. Phase 2 will tell you this in 1–2 weeks. If demand is low, pivot to a different problem/ICP and repeat.

**Q: Can I do this while employed?**
A: Yes. Budget 2–3 hours daily. Spread your 30 messages over 1–2 weeks. Do design and delivery work on weekends.

**Q: What's the difference between this and the main START_HERE guide?**
A: START_HERE is for selling an existing service to an existing network. This guide is for creating a NEW product from scratch, validating it, and launching it.
