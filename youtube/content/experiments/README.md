# Experiments

This folder holds detailed experiment writeups. Each experiment should be a single Markdown file created from `templates/EXPERIMENT.md` and include evidence, commands, screenshots and links to any code used.

Naming convention: YYYY-MM-DD-slug.md

Example files to add here:
- 2026-09-01-ai-agents-laravel.md
- 2026-09-07-zero-cost-saas.md

Keep experiments focused, reproducible and time-stamped. Link experiments from `content/BACKLOG.md` and `research/LEARNINGS.md` when relevant.
