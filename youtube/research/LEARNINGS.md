# Learnings — living knowledge base

Every meaningful discovery should be recorded here using the structure below. Do NOT fabricate results. Record facts and keep hypotheses separate from evidence.

Entry template

- Date: YYYY-MM-DD
- Area: (Titles / Thumbnails / Format / Pillar / Monetization / Production)
- Observation:
- Evidence: (links, video IDs, screenshots)
- Hypothesis:
- Action:
- Confidence: (Low / Medium / High)
