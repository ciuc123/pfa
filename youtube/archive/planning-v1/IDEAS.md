## I Let 3 AI Agents Build the Same Laravel API

Concept: Give three different AI agents (Copilot/Claude/Codex style) the same spec and compare outputs.

Why would someone click? Because it's a direct comparison with surprising differences likely to appear.

What happens? Each agent produces different code, architecture and tests; I review, run, and compare.

What is the experiment? Measure quality, runtime errors, and how much human fixing is required.

What could go wrong? Agents produce near-identical outputs or the experiment is too long to digest.

What would make the result surprising? One agent nails the architecture with minimal fixes.

Target viewer: backend devs curious about AI coding agents.

Potential thumbnail: three robot heads over a Laravel logo.

Related ideas: "I Gave Codex a Real Laravel Project"
