# Product Ideas (do not build without evidence)

Keep potential product ideas discovered through audience interaction. Do NOT immediately build these — collect evidence first.

Categories

- Developer templates
- Laravel starter kits
- AI workflows and scripts
- Guides and short courses
- SaaS micro-products
- Scripts and CLI tools
- Consulting packages

Product idea template

- Title
- Problem
- Target user
- Evidence (comments, requests, outreach)
- Possible solution
- Price hypothesis
- Distribution path
- Validation status
- Next test

Core rule

"Audience evidence before product investment."

How to validate

1. Collect repeated requests or paid interest.
2. Run a small pilot (free or paid at low price).
3. Use an email waitlist or landing page to measure intent.

Example (template)

- Title: Tiny Laravel Starter for SaaS
- Problem: Developers waste time configuring auth, billing and deployments.
- Target user: indie hackers and freelance devs.
- Evidence: (link to requests)
- Possible solution: a minimal repo + setup guide for €29.
- Price hypothesis: €29–€79
- Distribution: video walkthrough + pinned description link
- Validation status: IDEA
- Next test: create a landing page and collect 50 signups.
