# Topic Research Framework

Use this file to capture candidate topics and their evidence. Do not invent search volume or metrics.

Fields

- Topic
- Audience
- Search intent (how users might look for it)
- Curiosity angle (what makes this topic click-worthy)
- Trend sensitivity (low/medium/high)
- Evergreen potential (low/medium/high)
- Possible experiments
- Related topics
- Evidence (links, observations)
- Notes

How to use

- Fill a line per promising topic. Link back to `content/IDEAS.md` when a topic becomes an idea.
- Prefer topics that can be turned into a demonstrable experiment.

Example

- Topic: "Can AI debug my code?"
- Audience: backend devs
- Search intent: "AI debug", "AI find bug"
- Curiosity angle: high — people want a shortcut
- Trend sensitivity: high
- Evergreen potential: medium
- Possible experiments: give AI a reproducible bug and compare fixes
- Evidence: (link to potential agents)
